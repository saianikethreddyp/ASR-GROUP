### Design behavior for these names

This is not visible website copy, but it defines the intended presentation:

- A static editorial logo wall with fine horizontal and vertical rules.
- No automatic carousel; visitors should be able to see and recognize the names without chasing moving content.
- Desktop: four columns across three measured rows.
- Mobile: two columns with generous spacing.
- Logos begin in a consistent charcoal or warm-grey treatment.
- If a logo has an approved Gallery collection, hover or keyboard focus reveals a short line such as “Branded environment · Open gallery.”
- Tapping the logo opens the related Gallery folder only when genuine content exists.
- Names without an approved case/gallery remain non-clickable.
- Logo sizes are optically balanced so one wide logo does not overpower the others.
- If logo permission is unavailable, use a well-typeset company name instead of an unofficial or poor-quality logo.
